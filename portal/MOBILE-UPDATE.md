# Mobile portal update

Replace the complete portal folder, including the new mobile.css file. No SQL or Supabase settings need changing.

On phones and narrow tablets, use Menu to open navigation and account actions. Selecting a section closes the menu; Escape also closes it. Dashboard tables become labelled cards on phone-sized screens. Forms use single-column fields with larger controls, and previews use a more readable compact letterhead. Printed documents retain the existing A4 styling.

Local checks cover menu state, table labels, HTML references and the existing business logic. Please verify the affected screen on your phone after refreshing. If the old layout remains, close the tab and reopen the portal so the updated HTML and stylesheets load.
