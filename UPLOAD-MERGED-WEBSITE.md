# Complete merged website

The ambassador onboarding update and earlier review fixes are already merged into this complete website folder. You have already run the onboarding SQL, so you do not need to run it again.

Copy the contents of this folder into your existing website checkout, replacing matching files. Keep your existing Git repository metadata. Then commit and push using your usual hosting workflow. This package does not publish the website automatically.

After deployment, refresh the admin dashboard and open Application Review → Onboarding. The detailed onboarding guide is in INSTALL-ONBOARDING.md. Older installation instructions describe the earlier patch; that patch has already been merged here.
