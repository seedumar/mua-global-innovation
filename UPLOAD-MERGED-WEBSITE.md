# Complete merged website

The ambassador onboarding update, follow-up reminders and earlier review fixes are already merged into this complete website folder. You have already run the original onboarding SQL. Run the new `portal/backend/ambassador-onboarding-followups.sql` once for the follow-up date field and updated functions.

Copy the contents of this folder into your existing website checkout, replacing matching files. Keep your existing Git repository metadata. Then commit and push using your usual hosting workflow. This package does not publish the website automatically.

After deployment, refresh the admin dashboard and open Application Review → Onboarding. The latest guide is INSTALL-FOLLOWUPS.md. Older installation instructions describe earlier patches; those patches are already merged here.
