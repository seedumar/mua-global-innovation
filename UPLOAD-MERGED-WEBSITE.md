# Complete merged website

The ambassador Welcome Pack, onboarding checklist, follow-up reminders and earlier review fixes are already merged into this complete website folder. You already installed the onboarding and follow-up SQL. No new SQL is needed for the Welcome Pack.

Copy the contents of this folder into your existing website checkout, replacing matching files. Keep your existing Git repository metadata. Then commit and push using your usual hosting workflow. This package does not publish the website automatically.

After deployment, sign in to the ambassador portal and open Welcome pack. The latest guide is INSTALL-WELCOME-PACK.md. Admins can still open Application Review → Onboarding. Older installation instructions describe earlier patches; those patches are already merged here.
